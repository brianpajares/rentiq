# RentIQ Monetization Plan

## Principio

RentIQ debe monetizar por criterio experto y decision accionable, no por consumo de tokens. El flujo sin API mantiene bajo el costo operativo mientras valida demanda real.

## Embudo Recomendado

```text
1. Usuario entra a RentIQ
2. Evalua un departamento gratis
3. Ve resultado comparativo renta fija vs Airbnb
4. Copia paquete para ChatGPT o link fetch
5. Detecta incertidumbre: riesgos, regulacion, supuestos, compra
6. CTA a /premium
7. Compra reporte, llamada o plan Pro
```

## Oferta Inicial

### Reporte Premium - S/ 79

Para una unidad.

Incluye:

- Revision de supuestos.
- Veredicto ejecutivo.
- Riesgos principales.
- Checklist antes de decidir.
- PDF compartible.

### Decision Call - S/ 249

Para compradores o propietarios que quieren acompanamiento.

Incluye:

- Reporte premium.
- Sesion de 45 minutos.
- Revision de escenarios.
- Recomendacion final.

### Pro / Agentes - S/ 199 mensual

Para agentes, brokers o gestores.

Incluye:

- Varias evaluaciones.
- Plantilla con marca.
- Comparacion de unidades.
- Prioridad en revision.

## Donde Convertir

### Pantalla de resultado

Momento de mayor intencion. Mostrar CTA:

```text
Servicio premium
```

### Pagina de precios

Los planes pagos deben llevar a:

```text
/premium
```

### Paquete ChatGPT Export

El usuario puede analizar gratis con su cuenta, pero el Markdown puede cerrar con una recomendacion suave:

```text
Si necesitas validar esta decision con un reporte revisado, solicita RentIQ Premium.
```

## Por Que Esta Ruta Es Mejor Para MVP

- No hay costos de API.
- No hay riesgo de consumo accidental.
- No requiere login.
- No requiere base de datos.
- Monetiza trabajo de mayor valor.
- Permite aprender que objeciones reales tienen los usuarios.

## Siguiente Iteracion

Cuando haya demanda pagada:

1. Agregar formulario de lead en `/premium`.
2. Conectar Stripe Payment Link.
3. Generar PDF premium.
4. Agregar CRM ligero.
5. Medir conversion desde resultado a premium.
